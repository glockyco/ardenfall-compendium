# Sticky repository rules

Requirements about this repository. `AGENTS.md` holds orientation, commands, and the definition of verified work. The user-level rules hold working style that applies to every repository.

- Never edit generated or deployed output by hand. Change its source and regenerate it. Treat `site/static` and `pipeline/dist` as staging caches, not sources. A deploy artifact is identified by its `artifact-manifest.json`. Production deploys consume only release artifacts under `pipeline/artifacts/releases/*`. Fixture artifacts are never deployable. (Enforced by `artifact-staging.test.ts` and `openspec/specs/canonical-data/spec.md`.)
- Use `entities/<id>/entity.json` as the only cross-subsystem source of truth for entity shape. Do not duplicate its fields in TypeScript, SQL, or C#. (Enforced by `bun run check:entity-fields` and `openspec/specs/entity-extraction/spec.md`.)
- Fail fast when source-of-truth data is missing. Emit diagnostics or fail the slice. Add recovery only for an explicit, continuously verified contract. (Enforced by `validateDescriptorCoverage` in `pipeline/src/entities/registry.ts` and by `openspec/specs/entity-extraction/spec.md`.)
- Never bypass the pre-commit hooks. Commit without `--no-verify`. (Enforced by `lefthook.yml` and by the rule `.omp/rules/no-verify-commit.md`.)
- A test or smoke MUST judge behaviour, not source text. Do not read a `.svelte`, `.ts`, or config file and assert on its contents; assert on a read model, a built page, or a running process. A source-text assertion passes when a page renders nothing and fails when the same behaviour is written differently. (Enforced by the rule `.omp/rules/source-text-test.md`. The identity change found `each_key_duplicate` in a browser while every source assertion passed.)
- A probe MUST select its subject by the state under test, never by a fixture's id or name. The same test and smoke run against the synthetic fixture and a live export, and those share states but not names. (Source: `tooling.test.ts` "keeps prerender smoke independent of synthetic fixture names".)
- One fact, one producer. Do not copy a value another table already derives, and do not add a second way to compute it. A copied label or a second derivation is how ambiguous link text and mirrored map coordinates both shipped. (Enforced by `openspec/specs/relationship-graph/spec.md`, whose label resolver computes link text once.)
- An input whose absence disables a check is prohibited. Required data is a required parameter, and a missing one fails loudly; optional inputs and defaulted values silently switch guards off. (Enforced by the snapshot completeness gate in `controller/src/validate-snapshot.ts`.)
- Verify a reader-facing change in a browser, against a live export, before you call it done. Prerendered HTML hides a hydration error, and the fixture lacks shapes that live data carries. (Procedure: `'/Users/glockyco/src/github.com/glockyco/ardenfall-compendium/.omp/skills/live-extraction'`.)
